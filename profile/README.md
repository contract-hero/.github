## Claude Code tooling

- **[sui-pilot](https://contracthero.dev/sui-pilot/)**: a Claude Code plugin for Sui and Move. 800+ bundled docs, a Move language server bridge and a Sui Prover wrapper, so the agent writes correct Move. ([repo](https://github.com/contract-hero/sui-pilot))
- **[plugin marketplace](https://contracthero.dev/plugins/)**: install every Contract Hero plugin from one place. ([repo](https://github.com/contract-hero/plugin-marketplace))
- **[toolkit](https://github.com/contract-hero/toolkit)**: skills that turn agent output into self-contained HTML reports, explainers and diagrams.
- **[skypies](https://contracthero.dev/skypies/)**: a Mac app for the files your agents produce. Its Claude Code plugin sends them to your own devices over an end-to-end encrypted peer-to-peer link. ([plugin repo](https://github.com/contract-hero/skypies-plugin))
- **[code-forge](https://contracthero.dev/code-forge/)**: design spec and architecture playground for a multi-agent build system. ([repo](https://github.com/contract-hero/code-forge))

## Smart contracts

- **[Flow fungible token standard](https://github.com/onflow/flow-ft)**: I wrote the Fungible Tokens Metadata FLIP and `FungibleTokenMetadataViews`, the #6 most-imported contract on Flow mainnet (431 contracts), and the Fungible Token Switchboard. #2 contributor to the repo, whose `FungibleToken` is the #2 most-imported contract (3,424).
- **[Band Protocol oracle on Flow](https://github.com/onflow/band-oracle-contracts)**: port from Solidity to Cadence, through the Cadence 1.0 upgrade.
- **[Trade Wars](https://github.com/alilloig/trade-wars)**: a fully on-chain, massively multiplayer trading game on Sui.
- **[sui-pbo](https://github.com/contract-hero/sui-pbo)**: Physical Backed Objects on Sui, the port of EIP-5791.
